## Договорённости, которые легко потерять

* Один осмысленный коммит на задачу; `git add` только явными путями (могли идти
  субагенты в то же дерево).
* Все записи в БД — через `db.immediate_transaction(session)` (BEGIN IMMEDIATE).
* Ошибки POST → 303 + красный flash + латинский код; GET → страница ошибки
  (тексты — `app/messages_ru.py`). Flash одноразовый: в тесте читать страницу
  один раз после редиректа.
* В шаблонах про пользователя — только `request.state.user_view` (иначе
  DetachedInstanceError). См. D-014.
* Русские тексты в Python — только инструментом записи файлов, не PowerShell
  `Set-Content` (будет не-UTF-8 → SyntaxError).
